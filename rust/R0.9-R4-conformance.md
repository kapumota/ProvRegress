### R0.9-R4: verificación cruzada Python/Rust

#### Alcance

Este gate compara dos procesos distintos: `project_trace()` y `diff_graphs()` de
Python frente al binario de pruebas `provregress-conformance` de Rust. Usa los
mismos eventos observables congelados G01-G10 y comprueba que la serialización
canónica, `graph_hash` y `delta_hash` coincidan **byte a byte**. Los rechazos
G07-G09 se comprueban en sus etapas correspondientes; stdout debe quedar vacío.

No modifica el corpus F1-F3, el código Python de producción ni los schemas.
El adaptador Rust es exclusivamente de verificación y no genera experimentos.

#### Extensión numérica sin cambio de oráculo

Los golden F2/F3 no contienen números de punto flotante. La compatibilidad
adicional utiliza entradas sintéticas en pruebas separadas: -0.0, exponentes
pequeños y grandes, umbrales entre notación fija y científica, Unicode y
normalización a UTC. `canonical_json_bytes()` Rust ajusta la representación
de floats finitos al criterio de `json.dumps()` Python. Esta comprobación no
prueba equivalencia universal de todos los posibles `JsonValue`, por ejemplo
enteros fuera de los rangos representables en `serde_json`, ni verifica bytes
de un `ArtifactStore` real. Estas limitaciones deberán mantenerse explícitas.

#### Gates locales y remotos

```bash
cargo fmt --all
cargo fmt --all --check
cargo test --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo build --workspace --locked --bin provregress-conformance
python -m pytest -q research/verification/test_r09_cross_conformance.py
python -m pytest -q
python -m pip check
(cd tests/fixtures/provenance/r0_8 && sha256sum -c SHA256SUMS)
```

GitHub Actions incorpora un job independiente `Conformidad cruzada Python Rust`.
No se acepta omitir ese job ni declarar PASS a partir de la sola compilación.

#### Criterio de cierre

R4 queda cerrado cuando el CI de la rama apruebe los tres jobs y cuando los
oráculos conservados mantengan sus SHA-256. R5 auditará el alcance residual,
la reproducibilidad y la integración, sin afirmar resultados científicos.
